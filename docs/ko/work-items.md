# 개발 작업 안내

[English](../work-items.md) | [한국어](work-items.md)

문제 제보와 변경 제안은 [Issues](https://github.com/novelKR/agent-response-gateway/issues),
구현 검토는 [Pull requests](https://github.com/novelKR/agent-response-gateway/pulls)를 사용한다.

문제 제보에는 기대 동작, 실제 결과, 재현 절차와 관련 버전·설정 정보를 적는다.
인증정보와 비공개 데이터는 제거한다. 제안은 이전 논의를 다시 찾아보지 않아도
이해할 수 있도록 문제와 원하는 결과를 설명한다.

PR은 하나의 검토 가능한 목적을 갖고 관련 이슈와 검증 결과를 포함해야 한다.
[개발 절차](github-workflow.md)와 [기여 정책](../../CONTRIBUTING.ko.md)을 따른다.

제품 기능은 [지원표](conformance.md)와 [개발 방향](roadmap.md)을 참조한다.
특정 애플리케이션의 구현과 운영 기록은 해당 애플리케이션 저장소에서 관리한다.
