# Project work

[English](work-items.md) | [한국어](ko/work-items.md)

Use [Issues](https://github.com/novelKR/agent-response-gateway/issues) to report
problems and propose changes, and [pull requests](https://github.com/novelKR/agent-response-gateway/pulls)
to review implementations.

A useful report states the expected behavior, observed result, reproduction steps
and relevant version/configuration details. Remove credentials and private data.
Proposals should explain the problem and intended result without requiring readers
to reconstruct earlier discussions.

Each pull request should have one reviewable purpose, link its issue and include
relevant validation. Follow the [development workflow](github-workflow.md) and
[contribution policy](../CONTRIBUTING.md).

For product capabilities, read the [support matrix](conformance.md) and
[development direction](roadmap.md). Application-specific implementation and
operational records belong in that application's repository.
